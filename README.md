# YoutubeClone
YouTube Clone 🎥

A simple YouTube homepage clone built using HTML and CSS while learning frontend web development.

Features
Responsive YouTube-style layout
Header with search bar
Sidebar navigation
Video grid section
Channel profile images
Thumbnails and video information
CSS Flexbox & Grid usage
Technologies Used
HTML5
CSS3
Flexbox
CSS Grid

How to Run
Download or clone the repository
git clone <repository-link>
Open the project folder in VS Code
Open youtube.html
Run using Live Server
